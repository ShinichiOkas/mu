- **成果物のコードに絶対パスを書かない。** 読むファイル・書くファイルは、
  実行時の作業ディレクトリからの**相対パス**で指定する。
- 実走で起きたこと（036 repro-r1）: バグは正しく直り、受入基準もすべて PASS だったが、
  実装は次のようになっていた。

  ```python
  CUSTOMERS = "S:/tmp/mu-036/repro-r1/customers.csv"
  ```

  **そのディレクトリでしか動かないプログラム**になった。動作確認は通る——自分が居る場所で
  試すからである。壊れていることは、別の場所で走らせて初めて分かる。
- 自分の居場所を確かめるためにフルパスを**調べる**のはよい。**書き残す**のがいけない。
