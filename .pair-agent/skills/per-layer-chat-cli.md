mu の各自律性層には、その層だけを使う最小の CLI チャット `l{N}_chat.py`（`l0_chat.py`・`l1_chat.py` …）を用意する。師匠がその層を **実際に触って** 動きと質感を確かめられる窓口。

**Why:** 師匠の明示宣言（2026-07-03）。L0 完成後「僕が実際に触ってみられるように CLI のチャットアプリを作ってよ。`l0_chat.py` って感じで各層ごと最もシンプルな実装で」→「確定ルールとして登録」。師匠は動く具体物のシンプルさで質感を確かめる（[[mu-001-concept-l0]]）。早く薄い実物を触れる形で出すことを重視。

**How to apply:**

- 層 `l{N}.py` を完成させたら、対になる `l{N}_chat.py` を用意する。その層 **だけ** を使い、最もシンプルに。
- CLI は薄いドライバに徹する（会話履歴などの状態は CLI 側が持ち、層は無状態を保つ）。層のエラー契約はそのまま見せる。
- Windows コンソールでも落ちないよう入出力は UTF-8 にそろえる（cp932 で em-dash 等が落ちる既知の穴）。
