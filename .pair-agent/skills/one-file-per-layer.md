mu の自律性の各層は、**1 層 = 1 ファイル**に収める。`mu/l0.py`・`mu/l1.py`・`mu/l2.py` … と、層番号がそのままファイル名になる。

**Why:** 師匠の明示宣言（2026-07-02）。L0 実装を見て「`l0.py` の 1 ファイルに収まっているのがとても良い。これをこのプロジェクトの原則ルールにしよう。`l1.py`, `l2.py` と、各層 1 ファイル」。ミニマルの4軸（特に「機構の薄さ」「概念の少なさ」）を、ファイル構造のレベルで体現する。1 ファイルで層全体を一望できることを優先する。

**How to apply:**

- 新しい層を作るときは `mu/l{N}.py` を 1 つだけ作る。層を複数ファイルに分割しない。
- 1 ファイルに収まらなくなったら、それは「層が厚すぎ／責務を持ちすぎ」のシグナル。ファイル分割より先に、層の責務を見直す。
- テストは層ごとに `tests/test_l{N}.py`（必要なら実接続 `tests/test_l{N}_live.py`）。
- 関連: [[layer-by-layer-completion]]（内側から一層ずつ完成させる）
