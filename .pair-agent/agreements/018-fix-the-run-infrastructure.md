## 設計メモ

- ACL は所有者自身が `icacls /reset` で解除できる（実測）。**意図的回避は依然可能**なので
  検出層（protection_violations）は残る——二層構造（合意016）は変わらない。
- 凍結順序: 属性→ACL（逆だと自分の chmod が ACL に拒まれる）。解除は ACL→属性。
- 強制終了の残骸（ACL＋属性）は `thaw()`（tools 層の後始末ヘルパ）で解いてから入力を配置する。
- mu コアは tools に依存しない（コア依存最小・合意011）。保護ファイル一覧・deadline は
  **呼び出し側が注入する**（guard と同じ形）。
- 検出のコマンド単位化は「同じ破れを二度報告しない」（初回のみ ok=False）。停止の決定は
  L4 の guard が担う（tools 層は報告まで）。
