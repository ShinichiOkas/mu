## ゴール

L2 = **PDCA を明示的に乗せる層**。D は L1。L2 が足すのは **Reflect（C＋A）**。
「与えられたゴールに向かって自立実行」の最小形。

## 構造（確定）

- **再帰同一構造**: どの層も「**内側ループを規定回数回す → Reflect で判断 → 続行/停止**」。L2 が L1 を、（将来）L3 が L2 を、**同じ形**で管理する。層が増えても構造は1つ。
- **再帰の底 = 人間**（最上位の停止は人間）。各層は安全のため上限を持つが、**上限は自層ハードコードでなく呼び出し側が規定**（`l2_chat.py`／テスト／将来の L3）。
- L1 が無状態なので、N 回で切って Reflect を挟み、未達なら messages 再投入で再開しても**仕事が失われない**。

## L2 の定義

- `run(goal, tools, max_rounds, l1_max) → (messages, passed)`:
  - loop（`max_rounds` 上限・呼び出し側規定）:
    1. **D**: L1 を `l1_max` 回まで回す
    2. **C＋A（Reflect）**: 「goal は達成されたか？ 未達なら何が足りないか」を **構造化出力 `{passed: bool, reason: str, next: str}`** で1回問う
    3. `passed` → 終了 ／ 未達 → `next` を messages に再投入して継続（＝**そこで計画が生まれる**）
- **Plan は暗黙**（Reflect の `next` 再投入）。明示 Plan は後段。
- Reflect は **L0 の構造化出力**（`format` にスキーマ）で合否を確実に取る。
- **無状態**: 状態は messages（上位が持つ）。中断・再開は L1 同様。
