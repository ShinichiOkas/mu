# 合意 025 — 役割バインディングの透明化（継ぎ目修理・合成ローダー・床）

status: completed（2026-08-11。3フェーズ完了・313 green・クローズ前スモーク 4/4 期待どおり）
created: 2026-08-11
approved: 師匠「２５を開始」（2026-08-11。024 振り返りの違和感①②への決定論のみの対処として協議済み）

## 背景

024 振り返りの違和感（vision/024 に原文）:
①roles/* とコード内利用部のバインディングが利用者から不透明。「この範囲で選んでほしい」の
意思表示手段が無い。②検証済みロールセットが複数になるときのパッケージ単位が無い。
協議中に継ぎ目の不整合を実発見: PjM の process プロンプトの役割一覧は**全役割**
（pdm/pjm 含む）を表示するのに、人選の検証は task_roles（pdm/pjm 除外）に対して行われ、
範囲外は implementer へ静かにフォールバックする（l4.py `_process`）。
pjm.md は「use only the listed role names」と言っており、**見せる範囲と有効な範囲がズレている**。

方針（協議済み）: 意思表示＝「どのセットをロードするか」。決定論の機構だけを今入れ、
マニフェストの欄設計・ファイル移動・L5 によるセット自動選択は2ドメイン目と一緒にやる。

## スコープ（フェーズ＝コミット単位）

1. **A — 継ぎ目の不整合修理（TDD）**: PjM に見せる役割一覧を人選対象（task_roles）に
   絞る。一覧の組み立てを role_kb の公開関数（`staffing_lines`）に移し、
   **PjM が見る一覧と人間に見せる一覧を同じ関数から出せる**ようにする。
   回帰テストは実経路（Director 経由の process プロンプト内容）で書き、
   未修理コードで落ちることを先に確認する。
2. **B — 合成ローダー＋決定論の床（TDD）**: `load_roles(*paths)` で複数ディレクトリを
   合成できるようにする（後方互換: 引数なし＝"roles"、1個＝従来どおり）。
   床2つ: (1) **同名役割の衝突はエラー**（両方の出所を名指しする）
   (2) `missing_positions(roles)` — コードが名前を知る4ポジション
   （pdm / pjm / qa / implementer）の定義書の不足を返す公開関数。
3. **C — 透明性の表面＋明文化**: CLI / probe の起動時に「人選対象の役割一覧
   （staffing_lines＝PjM が見るものと同一）＋ポジションの不足」を表示する
   （chat_common に表示ヘルパ）。role_kb docstring と README 役割の節に
   バインディングを明文化: **呼び出し側が渡す dict ＝人選の範囲そのもの。
   意思表示はロードする集合（パスの合成）で行う**。

## 実行中に採る判断（AI の判断。事後確認対象）

- **一覧は「絞る」を採用**（ポジションに注記を付ける案ではなく）。pjm.md の
  「use only the listed role names」と一覧を一致させるのが趣旨。プロンプト変更＝
  挙動変化としてここに記録する（825 現在の測定への影響は「PjM が pdm/pjm を
  人選できなくなる」方向のみで、これは元々無効→フォールバックだった経路）。
- **4ポジションの不足はエラーにしない**（可視化に留める）。「定義書が無ければ
  知識ゼロで動いて失敗する——それが正しい挙動」という既存の明文哲学（README）を
  変えない。エラー（床）にするのは**合成時の同名衝突だけ**——新規経路なので互換の
  重しが無く、静かな上書きは今回取り除きたい不透明さそのもの。
- **存在しないディレクトリは従来どおり空集合**（互換維持）。docstring に明記する。

## 完了条件

- PjM の process プロンプトに pdm / pjm の行が並ばない（実経路テスト。未修理で落ちる）
- `load_roles` が複数パスを合成し、同名衝突が両出所を名指しするエラーになる
- `missing_positions` が4ポジションの不足を返す（全部あれば空）
- CLI / probe の起動表示に人選対象一覧（PjM と同じ関数）と不足が出る
- role_kb docstring / README にバインディング（dict＝人選範囲・意思表示＝ロードの合成）が明文
- テスト全 green 維持
