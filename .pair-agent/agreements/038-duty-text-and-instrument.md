# 合意 038 — 責務の文言と物差しを噛み合わせる

## 背景 — 師匠の問い

> そもそもの問いです、READMEをどうすることがゴールだと指示しましたか？
> 想定は無編集なのでしょうが、結果はゴールに違反していましたか？

責務 v1 の要求は「一致」だけだった。ところが監査は「実在する ⟺ 言及がある」＝**網羅**を
測っており、しかも**嘘と沈黙を同じ NG に潰していた**。残っている5走ぶんの成果物を
測り直した結果:

| 走 | 嘘（実装と矛盾する記述） | 沈黙（述べなくなった） | 保存（原本の記述の残存） |
|---|:---:|:---:|---|
| 032 R0 | **0** | 3 | （当時の原本が現存せず未測定） |
| 035 R1 | **0** | 5 | **0/300 行（0%）** |
| 035 R2 | **0** | 5 | 0% |
| 037 R1 | **0** | 3 | 64/300 行（21%） |
| 037 R2 | **0** | 3 | 63/300 行（21%） |

**5走を通じて、実装と矛盾する記述は一度も生まれていない。** v1 に照らせば mu は
一度も違反していなかった。3スプリント「破壊」と呼んでいたのは、**指示に無い要求に対する
不履行**である（→ CorrectionRecord `20260814-measured-against-an-unstated-requirement`）。

## 決めたこと

### 1. 責務の文言（北極星の題材そのもの）— v2

> この作業ディレクトリのリポジトリについて、README.md を実装と一致させ続けよ。実装が正であり、
> README.md の側を実装に合わせる（実装ファイルは変更しない）。**README.md は、実装を構成する
> ファイル・役割・それらの数について漏れなく述べ、かつ既に述べている事柄を減らさないこと。**
> 記述が実装と食い違うなら記述を直し、実装に無いものを述べているなら削る。だが、正しい記述を
> 理由なく落としてはならない。**すでに網羅かつ一致しているなら、何も変更しなくてよい。**

推敲の経緯（どちらも師匠の指摘）:

1. **停止条件を要求全体に揃えた**——私の初稿は停止条件が「すでに一致しているなら」のままで、
   **「一致だけ満たして止まる」が正解になってしまう**。北極星の難所は停止条件の側にあるので、
   ここがズレると測定の土台が崩れる
2. **網羅の範囲を「ファイル・役割・数」に限定した**——「実装について述べるべきことすべて」では
   範囲が無限に開き、誰も充足を宣言できない＝**停止条件が到達不能**になり、no-op が原理的に
   発火しなくなる。限定してあるから、**基線の監査 0 NG が「到達可能である」ことの実測の証拠**になる

**要求は言うが、検査器は渡さない**——どのファイル・どの数を検査するかは今も mu に渡していない。

### 2. 物差し — 違反を3軸に分ける

| 軸 | 何の違反か | 実装 |
|---|---|---|
| **嘘** (`truth`) | 一致 | README が実装について偽を述べている |
| **沈黙** (`covered`) | 網羅 | その件に触れなくなった |
| **保存** (`retention`) | 保存 | 原本の記述のうち成果物に残った割合（行の多重集合・句読点は正規化） |

旧 `ok` も併記して前後比較を保つ（[[measurement-instrument-stays-fixed-across-phases]]
「物差しを変えるときは、変えた回に新旧両方で測る」）。

## この分離が既に見せたこと

035（原本が tray に無い）と 037（原本が tray にある）は、旧物差しでは「残存 5.5% → 21%」という
量の差でしかなかった。3軸で見ると**失敗の種類が違う**:

- 035: 保存 **0%**——原本の記述を1行も残さず、英語の別文書に置き換えた
- 037: 保存 **21%**——原本を写しながら進み、途中で尽きた

**037 A（原本を書き手の手元に写す）が変えたのは、量ではなく失敗の種類だった。**
