# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純販売数**: sales.csvにおける当該商品コードの数量合計から、returns.csvにおける当該商品コードの数量合計を差し引いた値。
- **死に筋商品**: 純販売数が 0 件以下である商品。ただし、inventory.csvに存在する商品のみを対象とする。

## 受入基準
1. [ ] 報告書ファイル 'deadstock_report.txt' が存在すること。（検査: `Test-Path deadstock_report.txt` → 出力に「True」を含むこと）
2. [ ] 報告書に '死に筋商品リスト' という見出しが含まれていること。（検査: `Get-Content deadstock_report.txt` → 出力に「死に筋商品リスト」を含むこと）
3. [ ] 報告書に判定根拠として '純販売数' という言葉が含まれていること。（検査: `Get-Content deadstock_report.txt` → 出力に「純販売数」を含むこと）
4. [ ] 報告書に、inventory.csvに存在するが売上がない、あるいは返品が売上を上回る商品コードが具体的に記載されていること。

## 仕様
【目的】
inventory.csv（在庫）、sales.csv（売上）、returns.csv（返品）を用いて、死に筋商品を特定し、その根拠と共に報告書を作成する。

【定義】
- 純販売数 = (sales.csvの数量合計) - (returns.csvの数量合計)
- 死に筋商品 = inventory.csvに記載があり、かつ純販売数が0件以下である商品

【作業内容】
1. inventory.csv を読み込み、全対象商品リストを作成する。
2. sales.csv と returns.csv を集計し、商品ごとの「純販売数」を算出する。
3. 純販売数が0以下の商品を「死に筋商品」として抽出する。
4. 以下の構成で報告書 'deadstock_report.txt' を作成する。
   - 見出し：『死に筋商品リスト』
   - 抽出された商品コード、商品名、およびその判定根拠となった純販売数の値
   - 判定基準（純販売数0以下であること）の説明

- deadstock_report.txt
