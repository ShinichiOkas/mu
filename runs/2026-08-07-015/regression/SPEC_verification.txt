## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **正味販売数**: sales.csvにおける特定商品コードの数量合計から、returns.csvにおける同商品コードの数量合計を差し引いた値。
- **死に筋商品**: 正味販売数が0以下である、または在庫数（inventory.csv）が100個以上かつ正味販売数が20個未満である商品。

## 受入基準
- [ ] 報告書ファイル(dead_stock_report.txt)が存在すること（検査: `Test-Path dead_stock_report.txt` → 出力に「True」を含むこと）
- [ ] 報告書に死に筋商品として特定された商品コード(P003)が含まれていること（検査: `Get-Content dead_stock_report.txt` → 出力に「P003」を含むこと）
- [ ] 報告書に判定理由（正味販売数や在庫数などの根拠）が記載されていること（検査: `Get-Content dead_stock_report.txt` → 出力に「正味販売数」を含むこと）

## 仕様
【目的】
inventory.csv, sales.csv, returns.csvを用いて、死に筋商品を特定し、その根拠を添えた報告書を作成する。

【定義】
1. 正味販売数 = (sales.csvの数量合計) - (returns.csvの数量合計)
2. 死に筋商品の判定条件：
   - 正味販売数 ≦ 0
   - または、「在庫数(inventory.csv) ≧ 100」かつ「正味販売数 < 20」

【処理手順】
1. inventory.csv, sales.csv, returns.csvを読み込む。
2. 各商品コードごとに正味販売数を算出する。
3. 上記判定条件に基づき、死に筋商品を抽出する。
4. 抽出した商品について、「商品名」「在庫数」「正味販売数」を記載し、なぜ死に筋と判定したかの理由（どの条件に合致したか）を明記した報告書を作成する。

【成果物】
- ファイル名: dead_stock_report.txt
- 内容: 特定された死に筋商品の一覧とその判定根拠。
