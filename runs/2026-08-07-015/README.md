### VERIFIER FIRST が発火しなくなった（1）

プロセスは `architect → implementer(report.md) → qa` の3タスク。検査器タスクは作られていない。
**014 の Tool1/View1 事件の根が絶たれた**——「接地できない性質に検査器を作らせない」という
発火条件の限定が効いた。

同時に PdM の受入基準は**すべて接地可能な形**になった:

```
Test-Path report.md → 「True」
Get-Content report.md | Select-String 'Ollama','llama.cpp','vLLM','LM Studio' → 「Ollama」
Get-Content report.md | Select-String 'セットアップ','リソース消費量',… → 「セットアップ」
Get-Content report.md | Select-String 'http' → 「http」
```

### judge が実際に働いた（2）— 決定論 check が見逃す穴を捕まえた

QA は「各主張に出典 URL があるか」を judge にかけ、**FAIL** を受け取って `ACHIEVED: no` を書いた。

> FAIL: The requirement mandates that *each* claim about feature/performance differences must have
> a supporting source URL…

決定論 check は `http` が**1本でもあれば ok** を返す（現に ok だった）。014 で URL 1本の報告書が
検査を通ったのはこの穴である。**judge はそこを捕まえた**——接地できない性質
（「*各*主張に出典があるか」）は機械検査では測れないという設計判断の実証になっている。

judge は対象を取り違えた呼び出し（SPEC.md を報告書として渡した）にも
「これは仕様書であって報告書ではない」と fail を返しており、素直に堅い。

## 回帰確認（コーディング）— 解消していない。別の問題が出た

`probe_hard deadstock` は **15分で打ち切り**（`EXIT=124`）。014 に続いて収束しなかった。
ただし**止まっている理由は 014 と違う**:

- **VERIFIER FIRST は発火していない**（プロセスは3タスク。014 は `verify_logic.ps1` があった）。
  014 の原因は取り除けている
- 代わりに実装者が `test_inventory.py` を作り、**サンプル CSV を生成して入力を上書きした**

### 入力ファイルが破壊された（重大）

`inventory.csv` の中身が置き換わっている:

| | 内容 |
|---|---|
| 本来（013 / 014 の走行後も無傷） | `商品コード,商品名,在庫数` / `P001,ボールペン,120` |
| **015 の走行後** | `product_code,product_name,quantity` / `P001,Widget A,50` |

成果物 `dead_stock_report.txt` も「P002 / Widget B」となっており、**実データに対する答えではない**。
完走して QA が通していたら**偽・完遂**になっていた。

経路は合意007 B2 で**既知の穴として明示的に残した**もの:

- `protect()` は `write_file` / `edit_file` を拒否できるが、**`execute_command` 経由の生成は
  tools 層を通らない**。実装者は `python test_inventory.py` で CSV を書いた
- 塞ぐには任意のコマンド文字列の解析が要り、実行者の正当な能力を削る。だから
  「防がずに検出する」（`protection_violations()`）と決めていた
- ただし今回は **timeout 打ち切りのため検出報告そのものが出ていない**——
  「破れは検出できる」設計が、**走り切らないと働かない**ことが分かった

`roles/implementer.md` には既に「入力ファイルは読み取り専用。テストデータが必要なら別名の
一時ファイルを作り、最後に削除する」とある。**規範はあり、破られた。**

013 / 014 の同じ確認では起きていない。**015 の変更が原因かは1走では言えない**（確率的ブレの
可能性がある）。ただし「起こりうる」ことは確定した。
