# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純売上数**: sales.csvにおける当該商品コードの数量合計から、returns.csvにおける当該商品コードの数量合計を差し引いた値。
- **死に筋商品**: 純売上数が0以下、または在庫数に対して純売上数の比率（純売上数 / 在庫数）が10%未満である商品。

## 受入基準
- [ ] 報告書ファイル dead_stock_report.txt が存在すること（検査: `Test-Path dead_stock_report.txt` → 出力に「True」を含むこと）
- [ ] 報告書に死に筋商品の判定根拠（純売上数と在庫数の数値）が記載されていること（検査: `Get-Content dead_stock_report.txt` → 出力に「純売上数」を含むこと）

## 仕様
【目的】
提供された在庫表、売上履歴、返品履歴から、販売効率が悪く在庫を圧迫している「死に筋商品」を特定し、その根拠と共に報告書を作成する。

【定義】
1. 純売上数 = (sales.csvの数量合計) - (returns.csvの数量合計)
2. 死に筋商品 = 「純売上数 ≦ 0」または「(純売上数 / inventory.csvの在庫数) < 0.1」に該当する商品。

【入力ファイル】
- inventory.csv (商品コード, 商品名, 在庫数)
- sales.csv (日付, 商品コード, 数量)
- returns.csv (日付, 商品コード, 数量)

【出力成果物】
- ファイル名: dead_stock_report.txt
- 内容: 
    - 特定された死に筋商品のリスト（商品コード、商品名）
    - 各商品の判定根拠（在庫数および純売上数）

【検証条件】
- dead_stock_report.txt が出力され、内容に「純売上数」という文字列が含まれていること。
