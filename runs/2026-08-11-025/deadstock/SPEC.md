# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純売上数量**: 特定の商品の『sales.csv』における数量の合計から、『returns.csv』における数量の合計を差し引いた値。
- **死に筋商品**: 純売上数量が 0 以下である商品。

## 受入基準
1. [ ] 報告書ファイル『deadstock_report.txt』が存在すること（検査: `Test-Path deadstock_report.txt` → 出力に「True」を含むこと）
2. [ ] 報告書に『死に筋商品リスト』という見出しが含まれていること（検査: `Get-Content deadstock_report.txt` → 出力に「死に筋商品リスト」を含むこと）
3. [ ] 報告書に各商品の判定根拠となる『純売上数量』の数値が記載されていること（検査: `Get-Content deadstock_report.txt` → 出力に「純売上数量」を含むこと）
4. [ ] 在庫表（inventory.csv）に存在する商品コードが漏れなく判定対象となっていること

## 仕様
【目的】
inventory.csv, sales.csv, returns.csv の3つのファイルを分析し、死に筋商品を特定して報告書を作成する。

【定義】
1. 純売上数量 = (sales.csv の当該商品コードの数量合計) - (returns.csv の当該商品コードの数量合計)
2. 死に筋商品 = 純売上数量が 0 以下である商品

【処理詳細】
1. inventory.csv を読み込み、全商品コードを抽出する。
2. 各商品コードについて、sales.csv と returns.csv から数量を合算し、「純売上数量」を算出する。
3. 純売上数量が 0 以下の商品を「死に筋商品」として抽出する。

【成果物】
ファイル名: deadstock_report.txt
内容:
- 『死に筋商品リスト』という見出しを付けること。
- 特定された死に筋商品の「商品コード」「商品名」および、判定根拠となる「純売上数量」を明記すること。

【検査基準】
- deadstock_report.txt が存在すること。
- ファイル内に『死に筋商品リスト』および『純売上数量』の文字列が含まれていること。
