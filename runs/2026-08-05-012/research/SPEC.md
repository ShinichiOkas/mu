# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
ローカルで LLM を動かす実行基盤について、Ollama / llama.cpp / vLLM / LM Studio を比較し、mu（きわめてミニマルな汎用エージェント）の基盤として Ollama を使い続けるべきかを判断できる材料を、報告書にまとめてほしい。判断に効く観点で比べ、主張には必ず出典 URL を添えること。

## 操作的定義
- **判断に効く観点**: mu（ミニマルな汎用エージェント）の要件である「セットアップの簡便さ」「APIの互換性」「メモリ/リソース消費量」「モデルの更新頻度・導入コスト」の4項目と定義する。
- **報告書**: 比較表（Markdown形式）を含み、各ツールの特性、muへの適合性、および結論を記述したMarkdownファイル（report.md）とする。
- **出典URLの正当性**: 報告書に記載された全てのURLが、`check_sources.py` を実行した際にHTTP 200を返し、404やDNSエラーにならない状態であること。

## 受入基準
- [ ] 比較報告書 report.md が存在し、Ollama, llama.cpp, vLLM, LM Studio の4つのツールが網羅されていること。（検査: `Get-Content report.md` → 出力に「Ollama」を含むこと）
- [ ] 全ての主張にURLが添えられており、それらが check_sources.py で検証可能であること。（検査: `python check_sources.py` → 出力に「ALL_URLS_VALID」を含むこと）
- [ ] muの基盤としてOllamaを使い続けるべきかどうかの結論が明記されていること。（検査: `Get-Content report.md` → 出力に「結論」を含むこと）

## 仕様
【目的】
mu（ミニマルな汎用エージェント）の基盤として、現状のOllamaを使い続けるべきか、あるいは llama.cpp / vLLM / LM Studio への移行を検討すべきかを判断するための比較報告書を作成する。

【成果物】
- `report.md`: 以下の内容を含むMarkdown形式の報告書。

【報告書の内容】
1. **比較表**: 以下の4つのツールを、「セットアップの簡便さ」「APIの互換性（OpenAI API準拠か等）」「リソース消費量」「モデル導入コスト」の観点で比較すること。
   - 比較対象: Ollama, llama.cpp, vLLM, LM Studio
2. **詳細分析**: 各ツールのメリット・デメリットを記述し、特に「ミニマルなエージェント基盤」というmuの特性に照らして、どのツールが最適かを分析すること。
3. **結論**: Ollamaを使い続けるべきか否かの判断を明確に記述すること。
4. **出典**: 全ての技術的な主張に、根拠となる出典URLを明記すること。

【制約・検証条件】
- 捏造URLを禁止する。作成した `report.md` 内のURLは、`check_sources.py` を実行して `ALL_URLS_VALID` というマーカーが出力される状態でなければならない。
- 定義に基づいた「判断に効く観点」を網羅すること。
