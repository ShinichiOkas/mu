## 目的（人間の入力・原文）
佐藤・鈴木・高橋の3人が全員参加できる60分の会議『企画会議』を、2026-08-17〜2026-08-21 の営業時間（9:00-17:00）内で見つけて予約してくれ。この環境の予定表サービスは outlook.py（Outlook 風の CLI）で、予定の照会と予約は必ず `python outlook.py` を通すこと（引数なしで実行すると使い方が表示される）。全員の既存の予定と重ならない枠であることが必須。

## 操作的定義
- **営業時間**: 各営業日の 09:00 から 17:00 までの時間帯。
- **全員参加できる60分の会議**: 佐藤、鈴木、高橋の3名全員が、既存の予定（`python outlook.py busy` で出力される内容）および他の予約と重複せず、連続して60分間の空き時間を有している状態。

## 受入基準
1. [ ] 『企画会議』というタイトルの予約が、2026-08-17から2026-08-21の間の営業時間内に作成されていること。（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）
2. [ ] 予約された会議の参加者に、佐藤、鈴木、高橋の3名全員が含まれていること。（検査: `python outlook.py bookings` → 出力に「佐藤」を含むこと）
3. [ ] 予約された会議の参加者に、佐藤、鈴木、高橋の3名全員が含まれていること（鈴木の確認）。（検査: `python outlook.py bookings` → 出力に「鈴木」を含むこと）
4. [ ] 予約された会議の参加者に、佐藤、鈴木、高橋の3名全員が含まれていること（高橋の確認）。（検査: `python outlook.py bookings` → 出力に「高橋」を含むこと）
5. [ ] 予約済みリストに、今回の『企画会議』以外の不要な予約（テスト用などのダミーデータ）が含まれていないこと。（検査: `python outlook.py bookings`）

## 仕様
目的：佐藤・鈴木・高橋の3名全員が参加可能な60分の枠を2026-08-17〜2026-08-21の営業時間（09:00-17:00）内で特定し、予約する。

制約・定義：
- 営業時間：09:00-17:00
- 会議名：企画会議
- 所要時間：60分
- 参加者：佐藤、鈴木、高橋
- 必須条件：3名全員の既存予定および他の予約と一切重複しないこと。
- 操作手段：必ず `python outlook.py` CLI を使用すること。

手順：
1. `python outlook.py busy <name>` を用いて、佐藤、鈴木、高橋の3名の2026-08-17〜2026-08-21の予定を確認する。
2. 全員の空き時間が重複する60分間の枠を、営業時間内から1つ特定する。
3. `python outlook.py book "企画会議" <YYYY-MM-DD> <HH:MM> <HH:MM> 佐藤 鈴木 高橋` を実行して予約を確定させる。

成果物：
- `python outlook.py bookings` の出力結果において、指定条件を満たす『企画会議』の予約が1件のみ存在し、それ以外の不要な予約が存在しない状態にする。
