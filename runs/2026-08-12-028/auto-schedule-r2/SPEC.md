## 目的（人間の入力・原文）
佐藤・鈴木・高橋の3人が全員参加できる60分の会議『企画会議』を、2026-08-17〜2026-08-21 の営業時間（9:00-17:00）内で見つけて予約してくれ。この環境の予定表サービスは outlook.py（Outlook 風の CLI）で、予定の照会と予約は必ず `python outlook.py` を通すこと（引数なしで実行すると使い方が表示される）。全員の既存の予定と重ならない枠であることが必須。

## 操作的定義
- **営業時間**: 各営業日の 09:00 から 17:00 までの時間枠。
- **全員参加できる枠**: 佐藤、鈴木、高橋の3名全員が、既存の予定（python outlook.py busy で出力される内容）および他の予約済みの会議と重複していない 60 分間の連続した時間枠。

## 受入基準
1. [ ] 佐藤、鈴木、高橋の3名の空き時間を照会していること（検査: `python outlook.py busy 佐藤; python outlook.py busy 鈴木; python outlook.py busy 高橋`）
2. [ ] 2026-08-17〜2026-08-21 の営業時間内に、3名全員が空いている60分の枠を1つ特定していること
3. [ ] 特定した枠で `python outlook.py book` を実行し、予約に成功していること（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）
4. [ ] 予約実行時の標準出力に BOOKED マーカーが出力されたこと（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）

## 仕様
【目的】
佐藤・鈴木・高橋の3名が全員参加可能な60分の枠を、2026-08-17〜2026-08-21の営業時間（09:00-17:00）内で見つけ、『企画会議』として予約する。

【制約条件】
- 予約操作は必ず `python outlook.py` を使用すること。
- 参加者は「佐藤」「鈴木」「高橋」の3名であること。
- 期間：2026-08-17 〜 2026-08-21
- 時間帯：09:00 〜 17:00
- 会議時間：60分
- 全員の既存の予定と重複してはならない（重複した場合、`outlook.py` は CONFLICT を返し exit 1 となる）。

【定義】
- 営業時間：09:00-17:00
- 全員参加できる枠：佐藤、鈴木、高橋の3名全員が、`python outlook.py busy <name>` で出力される予定および `python outlook.py bookings` で出力される予約と重複しない60分間の時間枠。

【遂行手順】
1. `python outlook.py busy 佐藤`, `python outlook.py busy 鈴木`, `python outlook.py busy 高橋` を実行し、各人の予定を把握する。
2. 2026-08-17〜2026-08-21 の 09:00-17:00 の間で、3名全員が空いている連続した60分の枠を特定する。
3. `python outlook.py book 企画会議 <日付> <開始時刻> <終了時刻> 佐藤 鈴木 高橋` を実行して予約する。この際、成功すれば標準出力に "BOOKED <id> <date> <start>-<end>" が表示されることを確認する。

【完了基準】
- `python outlook.py bookings` を実行した際、出力結果に「企画会議」が含まれていること。
