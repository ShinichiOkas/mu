### 3. 内容の正確性確認
inventory.csv、sales.csv、returns.csv のデータを手動で集計し、純売上数を計算した：

| 商品コード | 商品名 | 在庫数 | sales合計 | returns合計 | 純売上数 | 死に筋判定 |
|------------|--------|--------|-----------|-------------|----------|------------|
| P001 | ボールペン | 120 | 99 | 2 | 97 | 否 |
| P002 | ノート | 80 | 31 | 0 | 31 | 否 |
| P003 | 消しゴム | 200 | 100 | 90 | 10 | 否（10は「10個未満」ではない） |
| P004 | マーカー | 45 | 14 | 0 | 14 | 否 |
| P005 | クリップ | 500 | 245 | 3 | 242 | 否 |
| P006 | はさみ | 30 | 9 | 0 | 9 | **是**（9 < 10） |
| P007 | ホッチキス | 60 | 0 | 0 | 0 | **是**（0 <= 0） |
| P008 | テープ | 150 | 64 | 0 | 64 | 否 |
| P009 | 付箋 | 90 | 25 | 0 | 25 | 否 |
| P010 | 蛍光ペン | 75 | 0 | 0 | 0 | **是**（0 <= 0） |

deadstock_report.txt の内容：
```
商品コード,商品名,在庫数,純売上数,判定理由
P006,はさみ,30,9,純売上数が10個未満のため
P007,ホッチキス,60,0,純売上数が0以下のため
P010,蛍光ペン,75,0,純売上数が0以下のため
```

報告書には、死に筋判定された P006、P007、P010 のみが記載されており、純売上数と判定理由が含まれている。P003（純売上数=10）は「10個未満」の条件に該当しないため、正しく除外されている。

### 4. SPEC と PURPOSE の整合性確認
PURPOSE（原文）: 「在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。」

SPEC.md は、PURPOSE の曖昧な指示を「純売上数 = sales合計 - returns合計」「死に筋 = 純売上数 <= 0 または（在庫あり ∧ 純売上数 < 10）」という操作的定義で明確化している。これは PURPOSE の制約を弱めるものではなく、むしろ具体化している。したがって、SPEC は PURPOSE の意図を忠実に反映している。
