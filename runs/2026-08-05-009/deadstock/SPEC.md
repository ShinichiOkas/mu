# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **実質売上数量**: sales.csvにおける当該商品コードの数量合計から、returns.csvにおける当該商品コードの数量合計を減算した値。
- **死に筋商品**: 実質売上数量が0以下である商品。具体的に、inventory.csvに存在する商品コードのうち、(sales.csvの数量合計 - returns.csvの数量合計) <= 0 となるものを指す。
- **報告書**: 死に筋商品の一覧（商品コード、商品名）と、その判定根拠（実質売上数量）を記載したテキストファイル（report.txt）。

## 受入基準
- [ ] 報告書ファイル report.txt が生成されていること（検査: `Get-ChildItem report.txt` → 出力に「report.txt」を含むこと）
- [ ] 報告書内に死に筋商品の判定根拠（実質売上数量）が含まれていること（検査: `Get-Content report.txt` → 出力に「実質売上数量」を含むこと）

## 仕様
【目的】
提供された在庫表、売上履歴、返品履歴から、実質的な売上がない「死に筋商品」を特定し、その根拠と共に報告書を作成する。

【入力データ】
- inventory.csv: 商品コード,商品名,在庫数
- sales.csv: 日付,商品コード,数量
- returns.csv: 日付,商品コード,数量

【ロジック】
1. inventory.csv に記載されている全商品について、以下の計算を行う。
   実質売上数量 = (sales.csv の当該商品コードの数量合計) - (returns.csv の当該商品コードの数量合計)
2. 「実質売上数量 <= 0」となる商品を「死に筋商品」と定義する。

【出力仕様】
- ファイル名: report.txt
- 内容: 
    - 死に筋商品の一覧（商品コード、商品名）
    - 各商品の実質売上数量（判定根拠として記載）

【検証用マーカー】
- 出力ファイル report.txt 内に "実質売上数量" という文字列を必ず含めること。
