## 目的（人間の入力・原文）
佐藤・鈴木・高橋の3人が全員参加できる60分の会議『企画会議』を、2026-08-17〜2026-08-21 の営業時間（9:00-17:00）内で見つけて予約してくれ。この環境の予定表サービスは outlook.py（Outlook 風の CLI）で、予定の照会と予約は必ず `python outlook.py` を通すこと（引数なしで実行すると使い方が表示される）。全員の既存の予定と重ならない枠であることが必須。

## 操作的定義
- **営業時間**: 各営業日の 09:00 から 17:00 までの時間帯。
- **全員参加できる枠**: 佐藤、鈴木、高橋の3名全員が、指定された開始時間から終了時間まで、既存の予定（python outlook.py busy で出力される内容）および他の予約と一切重ならない時間帯。
- **60分の会議**: 開始時刻から終了時刻までの差分がちょうど60分であること。

## 受入基準
1. [ ] 会議『企画会議』が 2026-08-17 〜 2026-08-21 の期間内に予約されていること。（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）
2. [ ] 予約された会議の参加者に 佐藤、鈴木、高橋 の3名が含まれていること。（検査: `python outlook.py bookings` → 出力に「佐藤」を含むこと）
3. [ ] 予約された会議の参加者に 佐藤、鈴木、高橋 の3名が含まれていること（鈴木）。（検査: `python outlook.py bookings` → 出力に「鈴木」を含むこと）
4. [ ] 予約された会議の参加者に 佐藤、鈴木、高橋 の3名が含まれていること（高橋）。（検査: `python outlook.py bookings` → 出力に「高橋」を含むこと）

## 仕様
【目的】
佐藤・鈴木・高橋の3名全員が参加可能な60分の空き時間を 2026-08-17 〜 2026-08-21 の営業時間（09:00-17:00）内で特定し、会議『企画会議』を予約する。

【制約条件】
1. 参加者: 佐藤、鈴木、高橋の3名全員。
2. 会議名: 『企画会議』
3. 期間: 2026-08-17 から 2026-08-21 まで。
4. 時間帯: 09:00 - 17:00 の間であること。
5. 枠の長さ: 正確に60分間であること。
6. 競合禁止: 3名全員の既存の予定（`python outlook.py busy <name>` で確認可能）および既に予約済みの枠と重なってはならない。

【操作手順】
1. `python outlook.py busy 佐藤`、`python outlook.py busy 鈴木`、`python outlook.py busy 高橋` を実行し、各人の予定を確認する。
2. 2026-08-17 〜 2026-08-21 の 09:00-17:00 の間で、3名全員が空いている連続した60分間の枠を特定する。
3. 特定した枠を用いて以下のコマンドを実行し、予約を行う：
   `python outlook.py book "企画会議" <YYYY-MM-DD> <開始時刻> <終了時刻> 佐藤 鈴木 高橋`

【成果物】
- `python outlook.py bookings` を実行した際に、『企画会議』が指定期間・参加者で登録されている状態。
