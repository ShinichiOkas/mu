# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
gen_data.py で 0〜99999 のランダム整数 1,000,000 個を data.txt に書き出し、analyze.py が data.txt を読み込んで値の上位10件と10区間のヒストグラムを表示するようにしてくれ。analyze.py の処理は3秒以内に完了しなければならない。最後に 'ANALYZE OK <経過秒>' を表示すること。

## 操作的定義
- **10区間のヒストグラム**: 0-99999の範囲を10,000刻みの10個の等間隔なバケット（0-9999, 10000-19999...）に分割し、各バケットに含まれる数値の個数を集計すること。
- **上位10件**: data.txtに含まれる1,000,000個の数値のうち、降順にソートした際の先頭10件のこと。
- **処理完了**: analyze.py の実行開始から標準出力に 'ANALYZE OK' が表示されるまでの経過時間が3.0秒以下であること。

## 受入基準
1. [ ] gen_data.py を実行すると data.txt が生成されること（検査: `python gen_data.py; Test-Path data.txt` → 出力に「True」を含むこと）
2. [ ] data.txt に1,000,000行の数値が書き出されていること（検査: `(Get-Content data.txt).Count` → 出力に「1000000」を含むこと）
3. [ ] analyze.py が上位10件を表示すること（検査: `python analyze.py` → 出力に「Top 10」を含むこと）
4. [ ] analyze.py が10区間のヒストグラムを表示すること（検査: `python analyze.py` → 出力に「Histogram」を含むこと）
5. [ ] analyze.py が最後に 'ANALYZE OK <経過秒>' の形式で出力すること（検査: `python analyze.py` → 出力に「ANALYZE OK」を含むこと）
6. [ ] analyze.py の処理が3秒以内に完了すること

## 仕様
以下の仕様に従い、データ生成スクリプトと解析スクリプトを作成してください。

### 1. 成果物
- `gen_data.py`: データ生成スクリプト
- `analyze.py`: データ解析スクリプト

### 2. 詳細仕様
#### gen_data.py
- 0から99999までの範囲のランダムな整数を1,000,000個生成し、`data.txt` に1行1数値の形式で書き出すこと。

#### analyze.py
- `data.txt` を読み込み、以下の項目を標準出力に表示すること。
    - **上位10件**: 全データの中の値が大きい順に10件の数値。
    - **10区間のヒストグラム**: 0-99999の範囲を10,000刻みの10区間に分け、各区間に含まれるデータの個数を集計して表示すること。
- **パフォーマンス制約**: 
    - データの読み込みから出力完了までの処理時間を3秒以内に収めること。
- **終了判定出力**: 
    - 処理の最後に必ず `ANALYZE OK <経過秒>` という形式で文字列を出力すること（例: `ANALYZE OK 0.45`）。

### 3. 定義
- 10区間のヒストグラム: [0, 10000), [10000, 20000), ..., [90000, 100000) の各範囲のカウント。
- 上位10件: 降順ソート後のインデックス0-9の要素。

### 4. 検証基準
- `python gen_data.py` 実行後、`data.txt` が存在し、行数が1,000,000行であること。
- `python analyze.py` 実行時、出力に "Top 10" および "Histogram" という見出しが含まれていること。
- `python analyze.py` の出力の最後に "ANALYZE OK" が含まれ、かつ実行時間が3秒以内であること。
