# Design Document: 企画会議 Booking Logic

## 1. 構造

### 1.1 ファイル構成
- `design.md`: 本設計書。
- (後続タスクで実装される) `find_slot.py`: 3名の空き時間を検索し、予約コマンドを特定するスクリプト。

### 1.2 データの流れ
1. **予定の収集**: 
   - `python outlook.py busy 佐藤`
   - `python outlook.py busy 鈴木`
   - `python outlook.py busy 高橋`
   を順に実行し、2026-08-17 〜 2026-08-21 の期間の予定を抽出する。
2. **空き時間の計算**:
   - 対象期間の各営業日（09:00-17:00）について、3名全員の予定を統合した「不可時間帯」のリストを作成する。
   - 09:00-17:00 の範囲内で、不可時間帯と重複しない連続した 60 分の枠を先頭から探索する。
3. **予約コマンドの生成**:
   - 特定した `YYYY-MM-DD` および `HH:MM` (開始) と `HH:MM` (終了) を用いて、`python outlook.py book` コマンドを構成する。
4. **予約の実行**:
   - 生成したコマンドを実行し、`BOOKED` メッセージを確認する。

### 1.3 責務の分割
- **探索ロジック**: `outlook.py busy` の出力をパースし、時間軸上の空き時間を判定する。
- **予約実行**: `outlook.py book` を呼び出し、結果の終了コードと出力を検証する。

## 2. 品質特性と実現構造

### 2.1 検証可能性
- **セルフテスト**: スクリプトは以下の形式で進捗と結果を標準出力に印字すること。
  - `[CHECK] 予定取得: OK`
  - `[CHECK] 空き枠特定: 2026-08-XX 10:00-11:00`
  - `[CHECK] 予約実行: SUCCESS`
  - 最終的に `[RESULT] SUCCESS` または `[RESULT] FAILED` を出力する。
- **正当性確認**: 予約完了後、`python outlook.py bookings` を実行し、出力に「企画会議」が含まれていることを確認する。

## 3. 設計規則

### 3.1 基本規則
- **入力ファイルは読み取り専用**: `calendar_data.json` および `outlook.py` を編集・削除・上書きしてはならない。
- **成果物の限定**: `design.md` 以外に、実行に必要な最小限のスクリプトのみを作成し、一時ファイル等を散らかさない。
- **操作手段の限定**: 予定の照会および予約は、必ず `python outlook.py` を介して行うこと。

### 3.2 予約コマンドの仕様
予約に用いるコマンドの正確な形式は以下の通りとする。

- **コマンド**: `python outlook.py book "企画会議" <YYYY-MM-DD> <HH:MM> <HH:MM> 佐藤 鈴木 高橋`
- **例**: `python outlook.py book "企画会議" 2026-08-17 10:00 11:00 佐藤 鈴木 高橋`

### 3.3 出力マーカー
- 成功判定用マーカー: `[RESULT] SUCCESS`
- 失敗判定用マーカー: `[RESULT] FAILED`
