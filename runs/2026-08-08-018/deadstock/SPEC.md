# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純売上数**: sales.csvにおける当該商品コードの数量合計から、returns.csvにおける当該商品コードの数量合計を差し引いた値。
- **死に筋商品**: 純売上数が0個以下である商品。inventory.csvに存在する商品コードを対象とする。

## 受入基準
1. [ ] 報告書ファイル（deadstock_report.txt）が存在すること（検査: `Test-Path deadstock_report.txt` → 出力に「True」を含むこと）
2. [ ] 報告書に死に筋商品の判定基準（純売上数の計算方法）が記載されていること（検査: `Get-Content deadstock_report.txt` → 出力に「純売上数」を含むこと）
3. [ ] 報告書に、純売上数が0以下の商品（例：P003などの計算結果）が具体的に列挙されていること（検査: `Get-Content deadstock_report.txt` → 出力に「P003」を含むこと）

## 仕様
【目的】
在庫表、売上履歴、返品履歴から「死に筋商品」を特定し、その根拠と共に報告書を作成する。

【定義】
1. 純売上数 = (sales.csvの数量合計) - (returns.csvの数量合計)
2. 死に筋商品 = inventory.csvに掲載されており、かつ純売上数が0個以下である商品

【入力データ】
- inventory.csv (商品コード,商品名,在庫数)
- sales.csv (日付,商品コード,数量)
- returns.csv (日付,商品コード,数量)

【タスク】
1. inventory.csvの全商品について、sales.csvとreturns.csvからそれぞれの合計数量を集計し、純売上数を算出すること。
2. 純売上数が0以下の商品を「死に筋商品」として抽出すること。
3. 以下の内容を含むテキストファイル `deadstock_report.txt` を作成すること：
    - 死に筋商品の判定基準（純売上数 = 売上合計 - 返品合計 が0以下であること）
    - 特定された死に筋商品のリスト（商品コード、商品名、および算出された純売上数）

【納品物】
- deadstock_report.txt
