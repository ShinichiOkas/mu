# SPEC — L4（PdM）が目的から定めた仕様
（L4 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
gen_data.py で 0〜99999 のランダム整数 1,000,000 個を data.txt に書き出し、analyze.py が data.txt を読み込んで値の上位10件と10区間のヒストグラムを表示するようにしてくれ。analyze.py の処理は3秒以内に完了しなければならない。最後に 'ANALYZE OK <経過秒>' を表示すること。

## 操作的定義
- **ランダム整数**: Pythonのrandom.randint(0, 99999)を用いて生成された整数。
- **10区間のヒストグラム**: 0-9999, 10000-19999, ..., 90000-99999 の10個の範囲ごとに、データに含まれる整数の個数を集計した結果。
- **上位10件**: data.txtに含まれる数値のうち、降順にソートした際の先頭10個の値。
- **処理時間**: analyze.py の実行開始から終了までを計測した壁時計時間（Wall-clock time）。

## 受入基準
- [ ] gen_data.py が data.txt を生成し、1,000,000行の数値が含まれていること（検査: `(Get-Content data.txt).Count` → 出力に「1000000」を含むこと）
- [ ] analyze.py が実行され、上位10件とヒストグラムを表示し、3秒以内に終了して特定のマーカーを出力すること（検査: `python analyze.py` → 出力に「ANALYZE OK」を含むこと）

## 仕様
以下の仕様で2つのPythonスクリプトを作成してください。

1. gen_data.py
- 0から99999までのランダムな整数を1,000,000個生成すること。
- 生成した各数値を1行に1つずつ、'data.txt' というファイルに書き出すこと。

2. analyze.py
- 'data.txt' を読み込み、以下の処理を行うこと。
  - データの数値的な上位10件（降順）を特定し、表示すること。
  - 0-9999 から 90000-99999 までの10区間のヒストグラム（各区間の出現回数）を計算し、表示すること。
- 処理時間制限：上記処理の完了までを3秒以内に収めること。
- 出力：処理完了後、標準出力に 'ANALYZE OK <経過秒>' と表示すること（例：ANALYZE OK 0.45）。

定義:
- ランダム整数: random.randint(0, 99999)を使用。
- 10区間ヒストグラム: [0, 10000), [10000, 20000), ..., [90000, 100000) の境界で集計。
- 上位10件: 全データの中の最大値から10番目の値まで。
- 処理時間: 実行開始から 'ANALYZE OK' の出力まで。

検証方法:
- (Get-Content data.txt).Count が 1000000 であること。
- python analyze.py を実行し、出力に 'ANALYZE OK' が含まれ、且つ表示された経過秒数が 3.0 未満であること。
