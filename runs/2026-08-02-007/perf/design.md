# Design Document: High-Performance Data Generation and Analysis

## 1. Structure
### File Configuration
- `gen_data.py`: Data generator. Produces a dataset of 1 million integer entries.
- `analyze_data.py`: Data analyzer. Processes the dataset to find the top 10 most frequent elements and generate a histogram.
- `data.txt`: Input file (generated by `gen_data.py`, consumed by `analyze_data.py`).

### Data Flow
1. `gen_data.py` $\rightarrow$ Generates 1,000,000 random integers $\rightarrow$ Writes to `data.txt`.
2. `analyze_data.py` $\rightarrow$ Reads `data.txt` $\rightarrow$ Computes frequencies $\rightarrow$ Extracts Top 10 $\rightarrow$ Outputs results.

### Responsibility Division
- **Generation**: Focus on fast I/O and uniform distribution of random numbers.
- **Analysis**: Focus on memory efficiency and time complexity for large-scale data processing.

---

## 2. Quality Attributes and Realization
### Performance
- **Generation**: Use a buffered write approach to handle 1 million entries efficiently.
- **Frequency Analysis**: Use a hash map (Python `dict` or `collections.Counter`) for $O(N)$ frequency counting.
- **Top 10 Extraction**: Use `heapq.nlargest` to ensure $O(N \log K)$ complexity where $K=10$, avoiding a full $O(N \log N)$ sort of the unique elements.
- **Histogram**: Use a frequency array (or the computed hash map) to map value ranges to counts.

### Verifiability (Self-Testing)
To avoid "false positives" (where a script exits 0 without doing anything), all scripts must print a specific ASCII marker upon successful completion of their primary logic.
- Marker: `[COMPLETED_SUCCESSFULLY]`
- The marker must be printed only after the final file write or output operation is confirmed.

---

## 3. Design Rules
### Implementation Constraints
- **Input Files are Read-Only**: `analyze_data.py` must open `data.txt` in read-only mode. It must not modify, truncate, or delete the input file.
- **Artifact Control**: Only the files explicitly named in this design (`gen_data.py`, `analyze_data.py`, `data.txt`) shall be created. Temporary files must be handled in memory or cleaned up immediately.
- **Randomness**: `gen_data.py` must use `random.randint(low, high)` to generate the integer entries.

### Technical Specifications
- **Data Volume**: Exactly 1,000,000 entries.
- **Complexity**: 
    - Frequency counting: $O(N)$
    - Top 10 selection: $O(N \log 10)$ via `heapq`.
- **Output Format**: 
    - Top 10 must be printed as `Value: Count` sorted by Count descending.

### Required ASCII Markers
- Success indicator: `[COMPLETED_SUCCESSFULLY]`
