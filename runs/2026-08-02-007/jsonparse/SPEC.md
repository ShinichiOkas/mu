## 目的（人間の入力・原文）
jsonparse.py 1ファイルで、標準ライブラリの json モジュールを一切使わずに JSON パーサを実装してくれ。parse(text) が dict/list/str/int/float/bool/None を返す。ネスト・文字列エスケープ（\" \\ \n \uXXXX）・数値（負数・小数・指数）・空配列/空オブジェクト・null/true/false を網羅する20件以上のセルフテストが python jsonparse.py --selftest で走り、全部通れば 'JSONPARSE OK <件数>' を表示して exit 0。

## 操作的定義
- **json モジュールを一切使わずに**: jsonparse.py のソースコード内に 'import json' または 'from json import' という文字列が存在せず、外部ライブラリへの依存もない状態。
- **文字列エスケープの網羅**: 以下のエスケープシーケンスを正しく処理し、デコード後の文字列を返すこと: \", \\, \n, および \uXXXX (Unicode 16進数 4桁)。
- **数値の網羅**: 符号 (正・負)、整数、小数 (点を含む)、指数表記 (e/E) を含む JSON 数値仕様を正しく float または int に変換すること。
- **20件以上のセルフテスト**: python jsonparse.py --selftest を実行した際、内部で 20 種類以上の異なる JSON 入力パターン（空オブジェクト {}、空配列 []、ネスト、型混在、境界値など）を検証し、すべて正解した場合のみ成功とみなす。

## 受入基準
- [ ] json モジュールのインポートがないこと（検査: `Get-Content jsonparse.py`）
- [ ] セルフテストが実行され、20件以上のテストを通過して指定のマーカーを出力すること（検査: `python jsonparse.py --selftest` → 出力に「JSONPARSE OK」を含むこと）

## 仕様
【タスク仕様】

1. 成果物: `jsonparse.py` (1ファイルのみ)

2. 制約:
- 標準ライブラリの `json` モジュールを一切使用してはならない（import 禁止）。
- 外部ライブラリの使用も禁止する。

3. 実装機能:
- `parse(text)` 関数を実装し、JSON形式の文字列を解析して Python の対応する型 (`dict`, `list`, `str`, `int`, `float`, `bool`, `NoneType`) で返すこと。
- 以下の JSON 仕様を完全にサポートすること:
    - 構造: ネストされたオブジェクト (`{}`) および配列 (`[]`)。空のオブジェクト/配列も含む。
    - 文字列: ダブルクォートで囲まれ、以下のエスケープシーケンスを処理すること: `\"`, `\\`, `\n`, `\uXXXX` (Unicode)。
    - 数値: 負数、小数、指数表記 (`e` または `E`) を含む数値。
    - 定数: `true` -> True, `false` -> False, `null` -> None。

4. セルフテスト機能:
- コマンドライン引数 `--selftest` が指定された場合、内部で 20 件以上のテストケースを実行すること。
- テストケースには、前述の「ネスト」「エスケープ」「数値（負数・小数・指数）」「空配列/空オブジェクト」「null/true/false」をすべて網羅させること。
- 全てのテストが成功した場合のみ、標準出力に `JSONPARSE OK <成功件数>` (例: JSONPARSE OK 25) と表示し、終了コード 0 で終了すること。
- 1件でも失敗した場合は、エラーを表示し、終了コード非ゼロで終了すること。
