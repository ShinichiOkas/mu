## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純販売数**: 特定の商品の 'sales.csv' における数量の合計から、'returns.csv' における同商品の数量の合計を差し引いた値。 (純販売数 = 総販売数 - 総返品数)
- **死に筋商品**: 純販売数が 0 以下の商品。 (純販売数 <= 0)

## 受入基準
1. [ ] 報告書ファイル 'deadstock_report.txt' が生成されていること（検査: `Test-Path deadstock_report.txt` → 出力に「True」を含むこと）
2. [ ] 報告書に、死に筋商品の判定基準（純販売数 <= 0）が明記されていること（検査: `Get-Content deadstock_report.txt` → 出力に「純販売数」を含むこと）
3. [ ] 報告書に、死に筋商品として判定された個別の商品コードが含まれていること（検査: `Get-Content deadstock_report.txt` → 出力に「P003」を含むこと）
4. [ ] 報告書に、各商品の「販売数」「返品数」「純販売数」の根拠数値が記載されていること（検査: `Get-Content deadstock_report.txt` → 出力に「数量」を含むこと）

## 仕様
【目的】
在庫表、売上履歴、返品履歴を分析し、死に筋商品を特定して報告書を作成する。

【定義】
- 純販売数 = (sales.csvにおける商品ごとの数量合計) - (returns.csvにおける商品ごとの数量合計)
- 死に筋商品 = 純販売数が 0 以下の商品

【インプット】
- inventory.csv (商品コード, 商品名, 在庫数)
- sales.csv (日付, 商品コード, 数量)
- returns.csv (日付, 商品コード, 数量)

【アウトプット】
- ファイル名: deadstock_report.txt
- 内容:
    1. 死に筋商品の判定基準（純販売数が0以下であること）の説明
    2. 特定された死に筋商品の一覧（商品コード、商品名）
    3. 各商品の判定根拠（総販売数、総返品数、および計算された純販売数）

【検証基準】
- deadstock_report.txt が存在すること。
- 報告書内に「純販売数」という言葉が含まれていること。
- 計算の結果、純販売数が0以下となった商品（例: P003は販売60に対し返品55+35=90のため純販売数-30となり死に筋に該当する）が正しくリストアップされていること。
