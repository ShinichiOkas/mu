## 目的（人間の入力・原文）
佐藤・鈴木・高橋の3人が全員参加できる60分の会議『企画会議』を、2026-08-17〜2026-08-21 の営業時間（9:00-17:00）内で見つけて予約してくれ。この環境の予定表サービスは outlook.py（Outlook 風の CLI）で、予定の照会と予約は必ず `python outlook.py` を通すこと（引数なしで実行すると使い方が表示される）。全員の既存の予定と重ならない枠であることが必須。

## 操作的定義
- **営業時間**: 各営業日の 09:00 から 17:00 までの時間枠。
- **参加可能**: 指定された時間枠において、`python outlook.py busy <name>` の出力に、その時間と重複する予定が一つも存在しない状態。
- **60分の会議**: 開始時刻から終了時刻までがちょうど60分間である時間枠。

## 受入基準
1. [ ] 佐藤、鈴木、高橋の3名が参加者として予約されていること。（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）
2. [ ] 予約された日時が 2026-08-17 から 2026-08-21 の間であること。（検査: `python outlook.py bookings` → 出力に「2026-08-」を含むこと）
3. [ ] 予約された時間枠が営業時間（09:00-17:00）内であること。（検査: `python outlook.py bookings`）
4. [ ] 予約が正常に完了し、BOOKED メッセージが出力されたこと。（検査: `python outlook.py bookings` → 出力に「企画会議」を含むこと）

## 仕様
【目的】
佐藤・鈴木・高橋の3名全員が参加可能な60分の会議『企画会議』を、2026-08-17〜2026-08-21の営業時間（09:00-17:00）内で特定し、予約する。

【制約条件】
1. 予約は必ず `python outlook.py` CLI を使用して行うこと。
2. 予約枠は、3名全員の既存の予定（`python outlook.py busy <name>` で確認可能）と一切重複してはならない。
3. 予約枠は 60分間であること。
4. 予約枠は 09:00 から 17:00 の間に完全に収まっていること。

【手順】
1. `python outlook.py busy 佐藤`, `python outlook.py busy 鈴木`, `python outlook.py busy 高橋` を実行し、2026-08-17〜2026-08-21 の各自の予定を抽出する。
2. 3名全員の空き時間が 60分以上連続し、かつ営業時間の範囲内にある時間枠を特定する。
3. `python outlook.py book "企画会議" <YYYY-MM-DD> <HH:MM> <HH:MM> 佐藤 鈴木 高橋` を実行し、予約を確定させる。

【納品物】
- `python outlook.py bookings` を実行した際に、『企画会議』が指定期間・営業時間内で予約されている状態で終了すること。
