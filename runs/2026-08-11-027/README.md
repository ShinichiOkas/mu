## 所見

- **設計（継ぎ目）は3ドメインとも初走から正しく機能した。** secretary の一気通貫・
  rnd の scientist/experimenter 分離（設計→実施→評価の順で人選された）・book の
  writer/editor 分離（editor の権限逸脱は両走とも観測ゼロ）。師匠の修正指示
  「例ではなく目的に応じて設計」の成果——役割の**構成**は設計から、**規範文**は失敗から。
- **escalate 2件はどちらも正直**（偽・達成ゼロ維持）。しかもどちらも「成果物は実は
  正しかった／良かった」のに検証の意味論が未整備で落ちた——新ドメインの本命の失敗は
  作業側でなく**検証側の語彙**（計測の再現とは何か・改稿の証跡とは何か）に出る、
  という一般パターンが3ドメインを通して見えた（コーディングの「表象への判定」、
  リサーチの「読んでいない出典」と同型の各ドメイン版）。
- **言語クラス（英語初稿）は3ドメイン目**（research r2/r4・book r1）。役割文で都度
  対処しているが、ドメイン横断の構造対処（例: 言語の指定を仕様の必須欄にする）を
  検討する価値がある——LONGTERM 候補。
- rnd r2 は 1424s と予算（1500s）に接近。計測実験は本質的に周回が重い——予算の
  見積もりはドメイン特性に依存する（観測のみ・対処不要）。
