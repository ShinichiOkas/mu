# SPEC — L4（PdM）が目的から定めた仕様
（L4 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
gen_data.py で 0〜99999 のランダム整数 1,000,000 個を data.txt に書き出し、analyze.py が data.txt を読み込んで値の上位10件と10区間のヒストグラムを表示するようにしてくれ。analyze.py の処理は3秒以内に完了しなければならない。最後に 'ANALYZE OK <経過秒>' を表示すること。

## 操作的定義
- **ランダム整数**: Pythonのrandom.randint(0, 99999)を使用して生成された整数
- **10区間のヒストグラム**: 0-9999, 10000-19999, ..., 90000-99999 の10個の範囲における出現回数の集計
- **上位10件**: data.txtに含まれる数値の中で降順にソートした際の先頭10個の値
- **処理時間**: analyze.py の実行開始から終了までの壁時計時間（Wall-clock time）が 3.0 秒以下であること

## 受入基準
- [ ] gen_data.py が存在し、実行後に 1,000,000 行の data.txt が生成されること（検査: `python gen_data.py; (Get-Content data.txt | Measure-Object).Count` → 出力に「1000000」を含むこと）
- [ ] analyze.py が data.txt を読み込み、上位10件とヒストグラムを出力し、完了マーカーを表示すること（検査: `python analyze.py` → 出力に「ANALYZE OK」を含むこと）
- [ ] analyze.py の処理時間が3秒以内であること（検査: `Measure-Command { python analyze.py } | Select-Object -ExpandProperty TotalSeconds`）

## 仕様
以下の仕様に従い、データ生成スクリプトと分析スクリプトを作成せよ。

1. 定義:
- ランダム整数: random.randint(0, 99999) で生成された整数。
- 10区間のヒストグラム: 0-9999から90000-99999まで10,000刻みの範囲ごとの個数集計。
- 上位10件: 全データの中の降順ソート済み先頭10件。
- 処理時間: analyze.py の実行時間が3.0秒以内であること。

2. 成果物:
- gen_data.py: 0〜99999のランダムな整数を1,000,000個生成し、1行1数値の形式で data.txt に保存する。
- analyze.py: data.txt を読み込み、以下の処理を行う。
    - 数値の上位10件を標準出力に表示する。
    - 10区間のヒストグラム（各区間の件数）を標準出力に表示する。
    - 処理時間を計測し、最後に 'ANALYZE OK <経過秒>' を出力する。

3. 検証基準:
- `python gen_data.py` 実行後、`data.txt` が作成され、行数が1,000,000行であること。
- `python analyze.py` 実行時、上位10件とヒストグラムが表示され、最後に 'ANALYZE OK' という文字列が含まれていること。
- `python analyze.py` の実行時間が3秒以内であること。
