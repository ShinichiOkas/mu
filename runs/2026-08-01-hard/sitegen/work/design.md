# Design Document: sitegen.py

## 1. 構造 (Structure)

### 1.1 ファイル構成
- **Input**: `md_src/*.md` (Read-only)
- **Output**: `site/*.html` (Generated)
- **Script**: `sitegen.py`

### 1.2 データの流れ
1. `md_src/` ディレクトリから `.md` ファイルを一覧取得する。
2. 各 `.md` ファイルの内容を読み込み、Markdown 構文を HTML タグに置換する。
3. 置換後のコンテンツを `site/[filename].html` として書き出す。
4. 生成した全 HTML ファイルのリストから、`site/index.html` (リンク集) を構築し書き出す。
5. 処理したファイル数をカウントし、指定の成功マーカーを出力する。

### 1.3 責務の分割
- **File Scanner**: `md_src/` 内の対象ファイルを抽出する。
- **Markdown Converter**: 正規表現を用いて Markdown 記法を HTML タグに変換する。
- **Site Builder**: 個別ページおよび `index.html` をファイルシステムに書き出す。
- **Reporter**: 実行結果（ページ数）を標準出力に印字する。

## 2. 品質特性と実現構造

### 2.1 検証可能性 (Verifiability)
- **成功マーカーの厳密性**: スクリプト終了時に、単なる `exit 0` ではなく、処理したページ数を変数として埋め込んだ `SITEGEN OK {count}` という文字列を正確に標準出力する。これにより、単に「落ちなかった」のではなく「期待した数だけ処理した」ことを外部から検証可能にする。
- **冪等性の確保**: `site/` ディレクトリが存在しない場合は作成し、既存ファイルがある場合は上書きする。

## 3. 設計規則 (Design Rules)

### 3.1 基本規則
- **入力ファイルは読み取り専用**: `md_src/` 内のファイルは `r` モードで読み込み、一切の変更・削除を行わない。
- **成果物の限定**: `site/` ディレクトリ内に `.html` ファイルのみを生成し、一時ファイルやログファイルを散らかさない。
- **文字コード**: UTF-8 で読み書きを行う。

### 3.2 REGEX_MAPPING (変換定義)
以下の正規表現を用いて置換を行う。置換順序は、より長いパターンまたは特殊なパターンを優先し、意図しない二重置換を防ぐ。

| Markdown 構文 | 正規表現 (Regex) | 置換後 (HTML) | 備考 |
| :--- | :--- | :--- | :--- |
| H1 見出し | `^#\s+(.*)$` | `<h1>\1</h1>` | 行頭の `#` とスペース |
| H2 見出し | `^##\s+(.*)$` | `<h2>\1</h2>` | 行頭の `##` とスペース |
| 箇条書き | `^[\*\-]\s+(.*)$` | `<li>\1</li>` | 行頭の `*` または `-` とスペース |
| リンク | `\[([^\]]+)\]\(([^)]+)\)` | `<a href="\2">\1</a>` | `[text](url)` 形式 |

※ 正規表現は `re.MULTILINE` フラグを使用して行頭 `^` を判定する。

### 3.3 Index Page 構築ロジック
- `index.html` は以下の構成とする：
  - 基本構造: `<html><body><ul>...</ul></body></html>`
  - リスト項目: 生成した各 `.html` ファイルの名前を元に `<li id="..."><a href="filename.html">filename.html</a></li>` の形式で動的に生成し、`<ul>` 内に配置する。

### 3.4 出力マーカー
- 正常終了時の標準出力文字列: `SITEGEN OK {count}` (例: `SITEGEN OK 3`)
