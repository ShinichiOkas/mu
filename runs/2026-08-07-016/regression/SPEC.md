# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **正味販売数量**: sales.csv における当該商品コードの数量の合計値から、returns.csv における当該商品コードの数量の合計値を差し引いた値。
- **死に筋商品**: 正味販売数量が 0 以下の商品、または正味販売数量が 1 以上であっても inventory.csv における在庫数が 100 個以上の商品。

## 受入基準
- [ ] 報告書ファイル (dead_stock_report.txt) が作成されていること（検査: `Test-Path dead_stock_report.txt` → 出力に「True」を含むこと）
- [ ] 報告書に死に筋と判定された商品コード（例：P003）が含まれていること（検査: `Get-Content dead_stock_report.txt` → 出力に「P003」を含むこと）
- [ ] 各商品について、死に筋と判定した根拠（正味販売数量や在庫数などの数値）が記述されていること

## 仕様
【目的】
提供された在庫表・売上履歴・返品履歴から「死に筋商品」を特定し、その根拠を明記した報告書を作成する。

【入力ファイル】
- inventory.csv (列: 商品コード, 商品名, 在庫数)
- sales.csv (列: 日付, 商品コード, 数量)
- returns.csv (列: 日付, 商品コード, 数量)

【定義】
1. 正味販売数量 = (sales.csv の数量合計) - (returns.csv の数量合計)
2. 死に筋商品の判定基準：
   - 正味販売数量 ≦ 0
   - または、正味販売数量 > 0 かつ inventory.csv の在庫数 ≧ 100

【成果物】
- ファイル名: dead_stock_report.txt
- 内容: 
  - 死に筋と判定された商品のリスト
  - 各商品について、なぜ死に筋と判定したかの根拠（正味販売数量および現在の在庫数）を記載すること。

【検証方法】
- dead_stock_report.txt が存在し、判定された商品コード（例: P003）と判定根拠となる数値が記述されていることを確認する。
