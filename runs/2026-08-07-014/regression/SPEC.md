（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **実質販売数**: sales.csvにおける特定商品コードの数量合計から、returns.csvにおける同商品コードの数量合計を差し引いた値。
- **死に筋商品**: 実質販売数が 0 件以下である商品。ただし、inventory.csvに存在する商品コードのみを対象とする。
- **報告書**: 死に筋商品のリストと、その判定根拠（実質販売数の内訳）を記述したテキストファイル（dead_stock_report.txt）。

## 受入基準
- [ ] 報告書ファイル dead_stock_report.txt が生成されていること（検査: `Test-Path dead_stock_report.txt` → 出力に「True」を含むこと）
- [ ] 報告書に死に筋商品として判定された商品名（例：消しゴム）が含まれていること（検査: `Get-Content dead_stock_report.txt` → 出力に「消しゴム」を含むこと）
- [ ] 判定根拠（実質販売数などの数値）が記載されていること（検査: `Get-Content dead_stock_report.txt` → 出力に「実質販売数」を含むこと）

## 仕様
【目的】
在庫表、売上履歴、返品履歴から死に筋商品を特定し、その根拠と共に報告書を作成する。

【定義】
1. 実質販売数 = (sales.csv の商品別数量合計) - (returns.csv の商品別数量合計)
2. 死に筋商品 = inventory.csv に記載があり、かつ実質販売数が 0 以下の商品

【入力ファイル】
- inventory.csv (商品コード,商品名,在庫数)
- sales.csv (日付,商品コード,数量)
- returns.csv (日付,商品コード,数量)

【タスク】
1. inventory.csv に記載されている全商品について、sales.csv と returns.csv を参照し、商品ごとの実質販売数を算出せよ。
2. 実質販売数が 0 以下の商品を「死に筋商品」として抽出せよ。
3. 以下の形式で報告書 'dead_stock_report.txt' を作成せよ。
   - 商品名
   - 判定根拠（例：売上合計 X個 - 返品合計 Y個 = 実質販売数 Z個）

【完了基準】
- dead_stock_report.txt が存在すること。
- ファイル内に、死に筋と判定された商品名および「実質販売数」という文言が含まれていること。
