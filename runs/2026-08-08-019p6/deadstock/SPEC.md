# SPEC — L5（PdM）が目的から定めた仕様
（L5 の生成物。定義・受入基準は仮定を含む。直接編集して直してよい）

## 目的（人間の入力・原文）
在庫表 inventory.csv・売上履歴 sales.csv・返品履歴 returns.csv から、死に筋商品を特定して報告書を作ってくれ。なぜ死に筋と判定したかも分かるようにして。

## 操作的定義
- **純売上数量**: ある商品コードについて、sales.csvの数量の合計からreturns.csvの数量の合計を差し引いた値。
- **死に筋商品**: 在庫表(inventory.csv)に記載されており、かつ純売上数量が0以下の商品。

## 受入基準
1. [ ] 報告書ファイル（deadstock_report.txt）が存在すること（検査: `Test-Path deadstock_report.txt` → 出力に「True」を含むこと）
2. [ ] 報告書に「死に筋商品一覧」という見出しが含まれていること（検査: `Get-Content deadstock_report.txt` → 出力に「死に筋商品一覧」を含むこと）
3. [ ] 報告書に「判定理由」という見出しが含まれていること（検査: `Get-Content deadstock_report.txt` → 出力に「判定理由」を含むこと）
4. [ ] 純売上数量が0以下となった商品コードが報告書に記載されていること

## 仕様
【目的】
在庫表、売上履歴、返品履歴を照合し、純売上数量が0以下である「死に筋商品」を特定して報告する。

【定義】
- 純売上数量 = (sales.csvにおける当該商品の数量合計) - (returns.csvにおける当該商品の数量合計)
- 死に筋商品 = inventory.csvに存在する商品であり、かつ純売上数量が0以下であるもの。

【タスク】
1. inventory.csv, sales.csv, returns.csv を読み込む。
2. 商品ごとに純売上数量を計算する。
3. 純売上数量が0以下の商品を抽出する。
4. 以下の構成で報告書『deadstock_report.txt』を作成する。
   - 「死に筋商品一覧」セクション：特定された商品コードと商品名を列挙する。
   - 「判定理由」セクション：なぜ死に筋と判定したか（例：純売上数量が〇個であり、0以下であるため）を具体的に記述する。

【納品物】
- deadstock_report.txt
